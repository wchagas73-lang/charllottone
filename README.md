# Charllottone | Landing page

Site institucional estático, sem banco de dados, desenvolvido para publicação no Cloudflare Pages.

## Estrutura
- `index.html`: conteúdo e seções da landing page.
- `styles.css`: identidade visual e responsividade.
- `script.js`: menu mobile e ano automático.
- `assets/`: imagens otimizadas em WebP fornecidas pelo cliente.

## Publicação no Cloudflare Pages
1. Crie um repositório GitHub separado chamado `charllottone`.
2. Envie todos os arquivos e pastas deste pacote para a raiz do repositório.
3. No Cloudflare, entre em Workers & Pages > Create application > Pages > Connect to Git.
4. Selecione o repositório `charllottone`.
5. Framework preset: None. Build command: deixar vazio. Build output directory: `/` (raiz).
6. Salve e aguarde a publicação.

## Atualizações futuras
Edite `index.html` para textos, links e horários. Substitua arquivos dentro de `assets/` para trocar fotos, mantendo os nomes ou atualizando os caminhos no HTML. Faça commit no GitHub para disparar uma nova publicação.
